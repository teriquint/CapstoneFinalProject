This folder has a fixed centered layout for all pages.

Files included:
- index.html
- instagram.html
- linkedin.html
- findings.html
- methodology.html
- style.css
- script.js

Important:
Open script.js and replace PASTE_YOUR_MAPBOX_TOKEN_HERE with your working Mapbox token.
Then open index.html in VS Code Live Preview.

To connect to GitHub:
Copy these files into your existing CapstoneFinalProject GitHub folder, choose Replace, then commit and push.
